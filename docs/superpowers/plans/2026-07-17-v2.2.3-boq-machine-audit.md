# Agent Pi V2.2.3 BOQ Machine Audit Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make BOQ productivity, duration, activity/calendar linkage, initial cash-flow allocation, and cross-batch semantic consistency deterministically machine-auditable.

**Architecture:** Extend the existing `boq_five_step_pricing` item build-up instead of creating a parallel capability. The business-core schema and audit own deterministic item validation; the server-core batch merger owns cross-batch semantic consistency and exact child-to-parent preservation.

**Tech Stack:** TypeScript, Zod 4, Bun test, existing tender capability envelopes and task-board pipeline.

## Global Constraints

- Release version is `2.2.3`.
- Child BOQ reports remain exact-range, report-only, and unable to spawn children.
- Numeric values remain unformatted decimal strings.
- No vector database, new runtime dependency, or prompt-only validation.
- Generated `release/` copies are excluded from source test discovery rather than edited by hand.
