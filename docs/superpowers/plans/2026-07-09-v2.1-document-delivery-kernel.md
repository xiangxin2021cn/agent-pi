# Agent Pi V2.1 Document Delivery Kernel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a requirement ledger, transactional long-document artifact tool, executable orchestration transitions, and complete-text Markdown audit to Agent Pi V2.1.

**Architecture:** Extend the existing task contract and bounded orchestration state instead of creating a parallel workflow engine. Session-scoped document artifact operations own section persistence and atomic assembly; Goal Audit consumes complete deterministic audit text while keeping reviewer context bounded.

**Tech Stack:** TypeScript, Bun test, Zod, Node.js filesystem APIs, existing session-tools-core and server-core session architecture.

## Global Constraints

- Preserve the current selected-source hard boundary and two-pass Goal Loop limit.
- Preserve existing uncommitted spawned-session handoff work.
- Do not introduce recursive sub-agent spawning.
- Do not require users to manage orchestration files manually.
- Do not claim strict DOCX/PDF template cloning in this slice.
