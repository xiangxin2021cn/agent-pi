Use on a fresh or migrated tender Business Project after installing a build with the V2.5 control plane.

## Manual path

1. **项目资料登记** — Register 2+ files; confirm「资料齐套」completes without spawning children. Creating the project opens **one** chat named after the project (not per-stage).
2. **招标文件解析** — Enter stage (reuse parent). `start` must not flood;「下一步」fills up to 2. Each doc gets MD under `Agent Pi Outputs/<id>/document-analysis/`. Accept MDs; stage must not require `evaluation_strategy`.
3. **Skip-ahead** — In a stage-2 session, `tender_capability init boq_five_step_pricing` must error (whitelist).
4. **BOQ 组价** — Briefs include `methodStandard.path` (C5.1). Serial pages. After all batches complete, pack merge + `施工资源消耗总表.md` + `construction_resource_schedule` appear. Confirm bidder commitments before planning.
5. **策划 4-A/B/C** — Overview shows substeps. Accept 4-A MD. 4-B requires both `tender-programme.msp.xml` and `tender-programme.p6.xml` plus histograms/S-curve. 4-C requires Work Plan DOCX + `submission_audit.md`.
6. **停止派发 / 重置编排** — Stop freezes new spawns; reset clears board without deleting accepted parse MDs.
7. **Migration** — Open a project with old `planning`/`submission` stage-state keys; banner appears; canonical `planning-and-submission` is readable.
8. **Single parent** — After document analysis completes,「进入下一阶段」must open the **same** parent chat (handoff message appears), not create `项目 · BOQ…`. Side-panel「新建任务」on an existing project opens the project parent. Chat workflow bar「下一阶段」must not spawn a second main session.
