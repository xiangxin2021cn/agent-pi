# Agent Pi 2.5.1 / Agent 派 2.5.1

Agent Pi 2.5.1 clarifies tender monitor button states during in-flight work, stops mid-flight retry loops, and lightens live-monitor polling load.

Agent 派 2.5.1 理清投标监控在进行中任务时的按钮状态，避免运行中仍提示失败并重复重试，并降低实时监控对系统的负担。

## Bug Fixes

- **Document-analysis false invalid / endless retry** — Child reports that cite pages with `locator`/`excerpt` (no `documentId`) are accepted for single-doc batches; previously they were quarantined as `.invalid.*` and the stage kept re-spawning. Status heals the newest quarantined report when it passes the lenient gate; auto-dispatch stops after 6 attempts pending explicit 重试.
- **Tender monitor button / load confusion** — While unfinished work is live, 「恢复未完任务」 becomes 「未完成任务正在进行中…」; setup stage shows 「资料登记完成，点击可查看结果」 after complete; 「下一步」 shows 「正在进行，请稍后…」 during in-flight batches; red invalid/failed retry banners hide mid-flight children so a second click does not re-quarantine. Live poll slowed to 45s and only statuses stages that still need attention.
