# Agent Pi 2.3.3 / Agent π 2.3.3

Agent Pi 2.3.3 closes the tender document-analysis deliverable loop: deterministic pack merge, formal Markdown summary, and sidebar access to tender workspace artifacts.

Agent π 2.3.3 补齐招标文件分析成果闭环：确定性合并 capability pack、写入正式 Markdown 摘要，并在侧栏暴露投标工作区产物。

## Features / 功能

- **Deterministic document-analysis merge** — When every document-analysis batch report is schema-valid, stage status/resume automatically concatenates those reports into `.agent-pi/business/tender/<projectId>/packs/document-analysis.json` without requiring the parent LLM to rebuild the pack.
- **确定性合并 document_analysis** — 全部批次报告校验通过后，阶段 status/resume 自动拼接写入 `packs/document-analysis.json`，不再依赖主会话模型手工合并。
- **Formal Markdown summary** — The same hook writes `Agent Pi Outputs/<parentSessionId>/document-analysis-summary.md` so humans can read the merged analysis beside other formal outputs.
- **正式 Markdown 摘要** — 同步生成 `Agent Pi Outputs/<主会话>/document-analysis-summary.md`，可在正式输出目录直接审阅合并结果。
- **Sidebar Tender Workspace tree** — Session files now surface `.agent-pi/business/tender/<projectId>` (packs, orchestration reports, audits) with a dedicated source pill, including watch updates.
- **侧栏投标工作区树** — 会话文件区挂载 `.agent-pi/business/tender/<projectId>`（packs / orchestration / audits），带独立来源标签并支持文件监视刷新。

## Improvements / 改进

- **Parent-session prompt updated** — Document-analysis dispatch text now tells the parent agent that runtime owns the pack merge and Markdown summary; the parent should focus on `evaluation_strategy` and `boq_reconciliation`.
- **主会话提示更新** — 文档分析派发说明改为由运行时负责 pack 合并与 Markdown 摘要；主会话专注 `evaluation_strategy` 与 `boq_reconciliation`。
