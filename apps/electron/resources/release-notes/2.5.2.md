# Agent Pi 2.5.2 / Agent 派 2.5.2

Agent Pi 2.5.2 softens tender stage gates so usable results advance the pipeline, publishes analysis MD into Official Outputs, adds a panel deliverables quality check, and keeps the Working Folder collapsed by default on tender main sessions.

Agent 派 2.5.2 放宽投标阶段门禁（有可用结果即可推进），把解析 MD 发布到正式输出，增加监控面板「成果质检并整理」，并默认收起主会话工作文件夹。

## Bug Fixes

- **Tender Official Outputs missing analysis MD** — When document-analysis batches complete, per-document customer Markdown is published into `Agent Pi Outputs/<parentSessionId>/document-analysis/` so the Session Files 「正式输出」 tree lists the real deliverables (not only the summary / registration notes).
- **Tender Working Folder auto-expanded** — Main-session file panel no longer force-opens the project Working Folder; Official Outputs stays the default expanded root so source browsing remains one click away but collapsed by default.
- **Soft stage gates (advance on results)** — Stage handoff no longer hard-blocks on batchId/sourceRefs/filename ritual, human-review clicks, deep-equal merge drift, dual MSP+P6 filenames, or secondary packs. Primary usable results (analysis / pricing / methodology MD) are enough to keep the pipeline moving; quality checks stay as warnings. Packs that are `not_ready` but non-empty no longer block entering the next stage.
- **Stage deliverables catalog + panel organize** — Monitor panel「成果质检并整理」builds `orchestration/stage-deliverables-<stage>.json`, heals Official Outputs mirrors without agent turns, and injects the catalog into stage handoff / BOQ briefs.
