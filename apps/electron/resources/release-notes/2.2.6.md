# Agent Pi 2.2.6 / Agent π 2.2.6

Agent Pi 2.2.6 is a controlled recovery patch for Tender Workbench multi-agent runs and custom DeepSeek V4 endpoints.

Agent π 2.2.6 是面向投标工作台多智能体执行和 DeepSeek V4 自定义端点的受控恢复补丁。

## Highlights / 亮点

- **Recover failed child handoffs** - The parent session still waits while child agents are active, but if a child crashes, goes stale, or loses its required report, the parent no longer waits forever. It can retry the child, ask for review, or continue with explicit missing-child gaps.
- **子智能体失败可恢复** - 子智能体仍在运行时主会话继续等待；但如果子智能体崩溃、超时或未写出既定报告，主会话不再永久卡死，可重试、转人工复核，或在明确记录缺失项后继续。
- **No fabricated child reports** - Even during recovery, the parent is still blocked from creating, editing, or replacing a child-owned handoff report path.
- **禁止伪造子报告** - 即使进入恢复流程，主会话仍不能创建、修改或替换子智能体专属 handoff 报告文件。
- **DeepSeek V4 custom endpoint capability** - Custom endpoint models named `deepseek-v4`, `deepseek-v4-pro`, `deepseek-v4-flash`, `deepseek-chat`, or `deepseek-reasoner` now register with 1M context and 384K max output defaults. The model field also accepts explicit overrides such as `deepseek-v4-pro@ctx=1000000@out=384000`; `ctx` controls context length and `out` controls single-response output length.
- **DeepSeek V4 自定义端点能力** - 自定义端点模型名为 `deepseek-v4`、`deepseek-v4-pro`、`deepseek-v4-flash`、`deepseek-chat` 或 `deepseek-reasoner` 时，默认注册 100 万上下文和 38.4 万最大输出。模型输入框也支持 `deepseek-v4-pro@ctx=1000000@out=384000` 形式的手动覆盖；`ctx` 控制上下文长度，`out` 控制单次回复输出长度。
- **Core runtime refresh** - Claude Agent SDK 0.3.214 and Anthropic SDK 0.112.3; Pi remains current at 0.80.10.
- **核心运行时更新** - Claude Agent SDK 升级至 0.3.214，Anthropic SDK 升级至 0.112.3；Pi 仍为最新的 0.80.10。

## Notes / 说明

This patch does not remove bounded multi-agent controls. It narrows them: active child work remains protected, while failed or missing child handoffs become recoverable instead of permanently blocking the project flow.

本补丁不是取消多智能体边界，而是收窄边界：运行中的子任务继续受保护；失败或缺失的子 handoff 改为可恢复状态，不再永久阻塞项目流程。
