# Agent Pi 1.2.7

Agent Pi 1.2.7 supersedes 1.2.6 with the same visual polish plus a release validation fix.

## Highlights

- **Keeps the Agent Pi visual refresh** — includes the transparent logo assets, fixed logo sizing, refined default theme, and the new Warm and Bronze themes from 1.2.6.
- **Document visual-planning settings localized** — adds the missing locale entries for the new document visual planning controls and professional visual chips.
- **Release validation fixed** — normalizes locale ordering and restores i18n parity, sorting, and coverage checks for GitHub Actions.

## 中文说明

- **保留 Agent Pi 视觉更新** — 包含 1.2.6 的透明 logo、logo 尺寸修复、默认主题精修，以及新增暖色和护眼古铜主题。
- **补齐文档图表规划设置文案** — 为新的文档图表规划控件和专业图表标签补齐多语言条目。
- **修复发布校验** — 重新规范 locale 排序，恢复 GitHub Actions 的 i18n parity、sorted、coverage 校验。

## Safety Notes

This release only changes visual assets, theme presets, version metadata, and locale strings. It does not change agent execution, file handling, model routing, or project data storage behavior.
