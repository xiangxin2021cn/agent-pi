# Agent Pi 2.3.1 / Agent π 2.3.1

Agent Pi 2.3.1 focuses on the Pi 0.83.0 runtime upgrade, HTML artifact preview, Claude Agent SDK uplift, and stability follow-ups from the V2.3.0 Self-Harness release.

Agent π 2.3.1 聚焦 Pi 0.83.0 运行时升级、HTML 产物预览、Claude Agent SDK 升级，以及对 V2.3.0 Self-Harness 发布后的稳定性跟进。

## Features / 功能

- **HTML artifact render preview** — Opening `.html` / `.htm` files from the working directory or Official Outputs now shows a sandboxed rendered preview (with Preview/Code toggle) instead of only the source viewer. Local artifact previews allow scripts so interactive simulations can run.
- **HTML 产物渲染预览** — 从工作目录或正式输出打开 `.html` / `.htm` 时，默认进入沙箱渲染预览（可在预览/代码间切换），不再只显示源码；本地产物预览允许脚本，以便交互式仿真正常运行。
- **HTML Save As** — The HTML preview header includes Save As, using the existing native save dialog to export a copy of the current HTML.
- **HTML 另存为** — HTML 预览标题栏新增“另存为”，复用系统保存对话框导出当前 HTML 副本。

## Improvements / 改进

- **Claude Agent SDK uplifted to 0.3.222** — Moves from 0.3.214 to 0.3.222 (beyond upstream craft-agents-oss v0.11.3's 0.3.220). Pulls in abort-listener leak fixes, richer process-exit diagnostics, improved rate-limit status reporting, and session-resume fixes for dash-leading IDs.
- **Claude Agent SDK 升级到 0.3.222** — 从 0.3.214 升到 0.3.222（高于上游 craft-agents-oss v0.11.3 的 0.3.220），包含 abort 监听泄漏修复、更完整的进程退出诊断、限流状态上报改进，以及以 `-` 开头会话 ID 的恢复修复。
- **Pi runtime uplifted to 0.83.0** — Bumps `@earendil-works/pi-ai` / `pi-agent-core` / `pi-coding-agent` from 0.80.10 to 0.83.0 across the monorepo. Adapts GitHub Copilot OAuth to the provider-owned `OAuthAuth` API (`githubCopilotProvider().auth.oauth` with `AuthInteraction` prompt/notify), and narrows catalog reads to `BuiltinProvider` after `getModels` stopped accepting dynamic-only providers like `radius`.
- **Pi 运行时升级到 0.83.0** — 全仓将 `@earendil-works/pi-ai` / `pi-agent-core` / `pi-coding-agent` 从 0.80.10 升到 0.83.0。GitHub Copilot OAuth 改为 provider 自有的 `OAuthAuth`（`githubCopilotProvider().auth.oauth` + `AuthInteraction` 的 prompt/notify）；模型目录读取收窄为 `BuiltinProvider`，以适配 `getModels` 不再接受仅动态注册的 provider（如 `radius`）。
