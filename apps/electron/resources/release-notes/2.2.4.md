# Agent Pi 2.2.4 / Agent π 2.2.4

Agent Pi 2.2.4 raises Tender Workbench BOQ pricing to the C5.1 item-level standard, adds a mandatory bidder-commitment gate before methodology planning, fixes session read-state persistence, simplifies the primary navigation, and refreshes the Claude and Pi runtimes.

Agent π 2.2.4 将投标工作台 BOQ 组价提升到 C5.1 逐项推导标准，在施工策划前新增投标人条件确认门禁，同时修复会话已读状态持久化问题、精简主导航并更新 Claude 与 Pi 运行时。

## Highlights / 亮点

- **C5.1 item-level BOQ pricing** - Every priced row must preserve its BOQ identity and source, interpret specification and payment scope, derive crew and bottleneck productivity with three scenarios, calculate six resource categories, apply dated VAT-exclusive rates, and reconcile pure direct unit cost with the item total.
- **C5.1 逐项 BOQ 组价** - 每条清单必须保留原始身份和来源，解释规范及计量支付范围，推导班组、瓶颈和三情景工效，核算六类资源，采用带日期且不含增值税的费率，并校核纯直接费单价与条目总价。
- **Controlled pricing batches** - Backend briefs carry immutable item data and allowed sources in batches of at most 12. Generic resource databases, prose summaries, incomplete coverage, unsupported rates, indirect markups, arithmetic errors, and cross-batch conflicts cannot pass readiness.
- **受控组价批次** - 后端按最多 12 条生成包含不可变清单数据和允许来源的任务简报；通用人材机数据库、叙述摘要、覆盖不全、无依据费率、间接费加成、算术错误及跨批次冲突均不能通过就绪门禁。
- **Bidder commitment gate** - Before WORK PLAN AND PROPOSED METHODOLOGY, users confirm proposed labour and management strength, equipment acquisition mode, material prices, camp arrangements, method and productivity revisions, sequence, timing, and subcontract decisions.
- **投标人条件确认门禁** - 编制 WORK PLAN AND PROPOSED METHODOLOGY 前，由用户确认劳动力及管理人员配置、设备投入方式、材料价格、营地安排、工法和工效修订、施工顺序、时间安排及分包决策。
- **Thread-aware unread handling** - Opening a parent task marks its complete descendant session tree as read. Child agents that finish while the parent is open remain read after restart.
- **会话树级未读处理** - 打开主任务会把完整后代会话树标记为已读；查看主任务期间完成的子智能体在重启后仍保持已读。
- **Focused Agent Pi navigation** - Scheduled Tasks, Event Triggers, and Agent Events are removed from the primary sidebar. Existing automation definitions and backend services remain intact for compatibility.
- **聚焦 Agent π 主导航** - 主侧栏移除定时任务、事件触发和智能体事件；已有自动化定义与底层服务继续保留以保证兼容。
- **Runtime refresh** - Claude Agent SDK 0.3.212, Anthropic SDK 0.112.2, and Pi 0.80.10.
- **运行时更新** - Claude Agent SDK 0.3.212、Anthropic SDK 0.112.2、Pi 0.80.10。
- **OAG research archived** - The ontology-oriented knowledge-base assessment is stored under `docs/research`; it is not part of the current product roadmap or runtime.
- **OAG 调研归档** - 本体型知识库调研已保存至 `docs/research`，但不纳入当前产品路线和运行时。

## Compatibility / 兼容性

No automation records are deleted. Existing deep links and backend automation services remain available, while the primary sidebar stays focused on document and enterprise project work.

本次不会删除任何自动化记录。已有深链接及底层自动化服务仍可使用，主侧栏则聚焦文档与企业项目作业。
