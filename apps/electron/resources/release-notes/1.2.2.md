# Agent Pi 1.2.2

Agent Pi 1.2.2 is a hotfix for version reporting and update-state consistency after the V1.2.1 release.

## Highlights

- **About version fixed** — The About page and update state now read Electron's packaged `app.getVersion()` instead of a workspace package version that could lag behind the app release.
- **Shared version source fixed** — `@craft-agent/shared/version` now reads the repository root package version, keeping agent prompts and user-agent strings aligned with the packaged app release.
- **Updater cache validation** — Stale cached installers without version metadata, or with a version that does not match the target update, are ignored instead of being treated as ready-to-install updates.
- **Linux release upload fixed** — The release workflow no longer expects a Linux AppImage blockmap file that electron-builder does not produce for the current Linux target.

## Safety Notes

If a running app window still shows an older version after installation, fully quit and restart Agent Pi so the new packaged assets and update state are loaded.
