# Agent Pi 2.6.6 Classic / Agent 派 2.6.6 经典版

**This is not DeepSeek Harness and not 3.x.** Agent Pi 2.6.6 is a Classic 2.x maintenance update on Claude Agent SDK + Pi. GitHub’s Latest badge currently points at the separate 3.x DSH line — download this build from the v2.6.6 page, not from `/releases/latest`.

**这不是 DeepSeek Harness，也不是 3.x。** 2.6.6 是非 DSH 架构的经典 2.x 更新（Claude Agent SDK + Pi）。GitHub Latest 徽章指向独立的 3.x DSH 产品线；请从本页下载 `Agent-Pi-x64.exe`，不要从 Latest 下 DSH 包。2.6.5 应用内自动更新也指向 Latest，因此不会、也不应被拉到 3.x；经典版请手动安装本包。

Agent Pi 2.6.6 restores Claude Opus 4.6 as a selectable model, uplifts Claude Agent SDK **0.3.229 → 0.3.241** and Pi **0.84.1 → 0.84.2**, and stops Explore mode from going silent when a tool is blocked.

Agent 派 2.6.6 重新开放 Claude Opus 4.6，升级 Claude Agent SDK 与 Pi，并修复探索模式遇到拦截工具后整轮哑火。

## Features

- **Claude Opus 4.6 is back as a selectable model** — restored from official Craft Agents OSS v0.11.4 (craft-agents-oss#1007). It appears again in the model pickers for direct Anthropic connections, Amazon Bedrock, and Pi-backed catalogs. Connections that previously had it force-migrated to Opus 4.8 get Opus 4.6 re-added automatically (one-shot — your default model is left untouched, and removing it again sticks). Opus 4.8 remains the default for new installs.
- **重新开放 Claude Opus 4.6** — 按官方 Craft Agents OSS v0.11.4 恢复。Anthropic 直连、Bedrock 与 Pi 目录均可再选。曾被强制迁到 4.8 的连接会一次性加回 4.6（不改默认模型；你再删掉就不再加）。新安装默认仍是 Opus 4.8。

## Improvements

- **Claude Agent SDK 0.3.229 → 0.3.241** and **Pi 0.84.1 → 0.84.2** — twelve Claude Code CLI patches (streaming, process-exit diagnostics, rate-limit status) plus Pi 0.84.2 catalog and DeepSeek/Bedrock/OpenAI stream fixes. Official Craft Agents OSS v0.12.0 is still on older runtimes (Claude 0.3.220 / Pi 0.80.6).
- **运行时升级** — Claude Agent SDK 到 0.3.241，Pi 到 0.84.2。官方 Craft Agents OSS v0.12.0 仍停在更旧运行时。
- **Classic linux/mac installers build after a Windows Release upload** — `Build Installers` also runs on `release: published`. v0/v1/v2 tags get macOS DMG/ZIP and Linux AppImage. v3.x DeepSeek Harness releases stay Windows-only so Classic packages are not attached to a 3.x download page.
- **Windows 发布后自动编经典版 linux/mac** — v2 标签会补 DMG/ZIP/AppImage；3.x DSH 发布页不挂经典包。

## Bug Fixes

- **Explore mode no longer goes silent when a tool is blocked** — official Craft Agents OSS v0.11.4 fix. Since SDK 0.3.220, `continue: false` on a PreToolUse block ended the turn before the model saw the reason. `blockWithReason` now keeps `continue: true` so the agent can suggest switching modes or submit a plan.
- **探索模式被拦工具不再哑火** — SDK 0.3.220 起 `continue: false` 会在模型看到拦截原因前结束回合。现改为 `continue: true`，可提示换模式或提交计划。
