# Agent Pi 1.2.4

Agent Pi 1.2.4 restores Goal Loop's automatic self-correction path when a recoverable tool failure is found during the audit.

## Highlights

- **Goal Loop self-correction restored** — Recoverable tool failures no longer force an immediate manual-review stop when the turn completed and still has an assistant result to improve from.
- **Next-pass quality loop preserved** — If the audit report identifies missing work and the goal still has iteration and wall-clock budget, Agent Pi now schedules the hidden improvement pass instead of only showing the audit report.
- **Safety stops retained** — Interrupted turns, turns without a final assistant response, explicit system error messages, repeated identical failures, and exhausted budgets still stop for manual review.
- **Regression coverage** — Adds a controller regression test proving that a missing-source/read failure with a corrective audit enters `continue` and carries the failed-tool context into the improvement prompt.

## Safety Notes

This change does not remove Goal Loop's hard-stop protections. Authentication/runtime error messages and repeated failures still require user review instead of looping indefinitely.
