# Agent Pi 2.2.2 / Agent π 2.2.2

Agent Pi 2.2.2 isolates professional-workbench conversations that share the same physical project folder and adds safe support for large local tender documents.

Agent π 2.2.2 隔离使用同一物理项目文件夹的专业工作台会话，并安全支持大型本地投标资料。

## Highlights / 亮点

- **Conversation isolation** - Tender, delivery, and investment projects are grouped by business project instead of only by working-directory path.
- **会话隔离** - 投标、实施和投资工作台按业务项目分组，不再只按工作目录路径混合显示。
- **Session-scoped workbench memory** - Each business conversation has its own Project Memory Lite namespace. Sessions and child agents can share a working directory without silently injecting another conversation's memory.
- **工作台会话级记忆** - 每个业务会话拥有独立的 Project Memory Lite 命名空间；即使会话和子智能体共用工作目录，也不会静默注入其他会话记忆。
- **Large local documents** - Files selected through the native file picker can be attached by path up to 2 GiB. A 200+ MiB PDF is copied by the filesystem and is not encoded into renderer memory or the model context.
- **大型本地文档** - 系统文件选择器选取的本地文件可按路径附加至 2 GiB；200 MiB 以上 PDF 由文件系统复制，不会编码进渲染器内存或模型上下文。
- **Reliable continuation and handoff** - Large attachments remain available by path when Goal Loop resumes or a controlled child agent receives the task.
- **可靠续跑与交接** - Goal Loop 续跑或受控子智能体接手任务时，大型附件仍以路径引用方式保持可用。

## Compatibility / 兼容性

Ordinary conversations retain the existing working-directory project-memory behavior. The new session-level isolation applies only to professional workbench conversations with an explicit business context.

普通会话继续沿用现有工作目录项目记忆；新的会话级隔离仅适用于具有明确业务上下文的专业工作台会话。
