# Agent Pi 2.0.1 / Agent π 2.0.1

Agent Pi 2.0.1 is a focused orchestration-control patch after the 2.0 architecture upgrade.

Agent π 2.0.1 是 V2.0 架构升级后的编排控制小修版本。

## Highlights / 亮点

- **Visible orchestration ledger** - The session Info popover now shows the current phase, selected-source hard boundary, task board, sub-agent lifecycle, progress ledger, evidence package path, and entropy alerts. The Goal badge adds only a compact orchestration hint.
- **编排进度账本可见** - 会话“信息”弹窗新增当前阶段、选中来源硬边界、任务板、子智能体生命周期、进度账本、证据包路径和熵告警；输入区 Goal badge 只显示简短编排状态。
- **File-backed bounded autonomy** - Orchestrated sessions now create `orchestration/briefs`, `reports`, `evidence-packages`, and `progress-ledger.json`, so long tasks can be inspected, resumed, and audited without broad context reconstruction.
- **文件化边界自治** - 编排会话会生成 `orchestration/briefs`、`reports`、`evidence-packages` 和 `progress-ledger.json`，让长任务可检查、可续跑、可审查，不再依赖宽泛上下文重建。
- **Narrow sub-agent dispatch** - Spawned agents receive only a brief path, allowed sources, report path, and evidence package path when orchestration is active.
- **子智能体窄派发** - 编排启用时，子智能体只接收 brief 路径、允许来源、报告路径和证据包路径。
- **Evidence-first Goal Audit** - Goal Audit writes a compact evidence package before model review and prefers it over scanning conversation history or the working directory.
- **证据优先 Goal Audit** - Goal Audit 在模型审查前写入紧凑 evidence package，并优先使用它，而不是先扫描会话历史或工作目录。
- **Narrow BOQ pricing stays scoped** - Requests such as “only price the MEDIAN BARRIER page” now remain serial and scoped instead of being promoted into full workbook multi-agent orchestration.
- **窄范围 BOQ 组价不再过度编排** - 类似“只对 MEDIAN BARRIER 页组价”的任务会保持串行和限定范围，不再自动升级为全工作簿多智能体流程。
- **No recursive sub-agent spawning** - Spawned sub-agents are instructed and guarded from spawning further child sessions. Oversized work must be handed back to the main session as structured gaps and recommendations.
- **禁止子智能体递归派生** - 子智能体不再继续派生子子智能体；任务过大时必须通过结构化交接把缺口和建议交回主会话。
- **Claude Agent SDK 0.3.202** - The Claude Agent SDK dependency is refreshed from 0.3.201 to 0.3.202. Anthropic SDK and Pi packages were already current.
- **Claude Agent SDK 0.3.202** - Claude Agent SDK 从 0.3.201 升级到 0.3.202；Anthropic SDK 和 Pi 组件已是当前最新版。

## Safety Notes / 安全说明

Multi-agent deep mode still exists for genuinely full-workbook, full-report, and large multi-source tasks. This patch only prevents narrow, explicitly bounded work from being expanded into extra sheets, chapters, reviews, or spawned-agent layers.

多智能体深度模式仍然用于真正的全工作簿、完整报告和大型多来源任务。本补丁只阻止明确限定范围的任务被扩展成额外工作表、章节、审查或多层子智能体。
