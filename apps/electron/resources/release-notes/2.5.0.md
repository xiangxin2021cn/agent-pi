# Agent Pi 2.5.0 / Agent 派 2.5.0

Agent Pi 2.5.0 delivers the tender workbench control plane, keeps live monitoring across chat navigation, fixes Overview starvation timeouts, and uplifts the Claude Agent SDK.

Agent 派 2.5.0 交付投标工作台控制面，切到对话后仍可监控补位，修复回到监控面板时的超时假死，并升级 Claude Agent SDK。

## Features

- **Tender workbench V2.5 control plane** — Four controllable stages (资料登记 → 招标文件解析 → BOQ 组价与资源汇总 → 策划/进度/出稿). `start` binds the parent and queues work; **下一步 / 停止派发 / 重置编排** drive concurrency. Selective **重试** for failed/invalid batches. Human-reviewed parse MD remains a first-class gate.
- **Single project parent session** — Stages advance on one continuous parent with handoff messages; document/BOQ children stay for parallel heavy work. Stale deleted parent pointers heal on status/advance.

## Improvements

- **Monitor across chat** — Project-scoped live monitor keeps fill-up while reading the main/child session; ticks `status` first and only `resume` stages with pending work.
- **Packaged runtime** — `@anthropic-ai/claude-agent-sdk` **0.3.226 → 0.3.227**; `@earendil-works/pi-ai` / `pi-coding-agent` remain **0.84.1** (latest); `@anthropic-ai/sdk` → ^0.116.0; `@modelcontextprotocol/sdk` → ^1.30.0. MinerU Open API 0.5.9 and Git for Windows 2.55.0 unchanged.

## Bug Fixes

- **Returning to Overview timed out / froze** — Document-analysis status no longer rewrites unchanged briefs every tick; stage runs are serialized and yield to the event loop; Overview/Host stop parallel stage storms; project list is cached so the monitor paints immediately; `businessProjects:list` timeout raised to 120s as a backstop.
- **Failed subtasks had no restart path** — Per-row / banner selective `retryBatchIds` re-queues only chosen batches.
- **Legacy parent pointer heal** — Deleted board/parent pointers no longer open “此会话已不存在” or flood parent-missing errors.
