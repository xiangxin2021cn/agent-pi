# Agent Pi 1.3.0

Agent Pi 1.3.0 upgrades the app from a document workbench into a stricter professional delivery system for long document tasks, enterprise knowledge reuse, and multi-agent report production.

## Highlights

- **Document workflow modes** — adds Quick, Professional Document, Strict Delivery, and Multi-Agent Deep modes so users can choose between lightweight work, evidence-backed report production, strict delivery gates, and chapter-agent collaboration.
- **Strict delivery quality gates** — Goal Loop now reviews sources, evidence matrices, template fidelity, professional visuals, export formats, formatting evidence, chapter handoffs, and final synthesis ownership when strict/deep document modes are active.
- **Enterprise Knowledge Base** — knowledge files are copied into stable app-level storage, indexed into `knowledge-base/index.md`, grouped by folder, previewable/editable/exportable in the UI, and loadable from the chat data-source selector with single-entry or select-all selection.
- **Structured knowledge import** — Knowledge Base file ingestion supports structured Markdown preparation for common document and data inputs before creating file-memory MCP sources.
- **Professional document intelligence** — document plans can require source-backed diagrams, tables, construction Gantt visuals, investment tables, GIS-style figures, simulation/CAE summaries, and export-ready assets where richer professional expression is needed.
- **Model reasoning protocol** — Professional Document, Strict Delivery, and Multi-Agent Deep modes include bounded critical reasoning for decomposition, opposing-case review, third-party challenge, revision, and risk-qualified conclusions without forcing Quick mode into a rigid answer format.

## 中文说明

- **文档工作流模式** — 新增快速模式、专业文档模式、严格交付模式、多智能体深度模式，可在轻量任务、证据化报告、严格交付门禁和章节智能体协作之间切换。
- **严格交付质量门禁** — 严格/深度文档模式下，Goal Loop 会审查来源、证据矩阵、模板保真、专业图表、导出格式、排版证据、章节交接和最终统稿责任。
- **企业知识库** — 知识文件会复制到应用级稳定存储，生成 `knowledge-base/index.md` 索引，按文件夹归类，可在 UI 中预览、编辑、导出，并可从对话框数据源选择器按条目或全选加载。
- **结构化知识入库** — 知识库文件导入支持常见文档和数据输入先转结构化 Markdown，再创建 file-memory MCP 知识源。
- **专业文档智能** — 文档计划可按需要要求有来源支撑的流程图、表格、施工甘特图、投资表、GIS 表达、仿真/CAE 摘要和可导出图文资产。
- **模型推理协议** — 专业文档、严格交付和多智能体深度模式内置有界批判推理：拆解、正反推演、第三方质疑、修正复盘和带条件风险的结论，同时保持快速模式轻量。

## Safety Notes

Knowledge Base sources still require explicit user loading or selection before use. Strict delivery gates are intended to prevent unaudited reports from being accepted; they do not fabricate missing sources, charts, exports, or template-fidelity evidence.
