# Agent Pi 2.5.3 / Agent 派 2.5.3

Agent Pi 2.5.3 stops large tool streams from crashing the app, and makes the tender monitor continue existing child sessions instead of spawning duplicates on refresh/resume.

Agent 派 2.5.3 修复大工具输出撑爆主进程导致自动退出，并让投标监控在刷新/恢复时接续已有子会话，避免重复派发浪费资源。

## Bug Fixes

- **Main process crash on huge tool output** — Streamed tool output (`accumulateOutput`) is capped at 4 MiB per tool call with a truncation marker. Oversized PDF/OCR/Excel streams no longer throw `RangeError: Invalid string length` and storm `stability.log`.
- **大工具输出撑崩主进程** — 单次工具流式输出内存上限 4 MiB，超出截断并丢弃后续增量，避免 `Invalid string length` 异常风暴与自动退出。
- **Tender monitor respawned idle children** — Idle child sessions keep their `sessionId`; resume/advance continues the same session via `sendMessage` instead of spawning a new one. Monitor adds **暂停补位 / 恢复补位** (status-only vs fill-up).
- **监控刷新重复派生子会话** — 空闲子会话保留绑定并接续同一会话；监控支持暂停/恢复补位，停止盲目新建对话。
