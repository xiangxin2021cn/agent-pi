# Agent Pi 2.2.1 / Agent π 2.2.1

Agent Pi 2.2.1 focuses on document quality and tender-production continuity. It keeps ordinary writing tasks lightweight while making the Tender Workbench a connected pipeline from source analysis through BOQ pricing, methodology, programme/resources/cost/cash flow, formal submission documents, and final audit.

Agent π 2.2.1 聚焦文档质量与投标生产连续性。普通写作任务保持轻量；投标工作台则升级为从资料分析、BOQ 组价、施工方法论、进度/资源/成本/现金流、正式递交文件到最终审查的连续流水线。

## Highlights / 亮点

- **Native Quick and Guarded Quick** - Native Quick stays close to upstream-style lightweight execution without task contracts, Document Plans, or automatic Goal Loop repair. Guarded Quick keeps lightweight source boundaries and explicit checks for tasks that still need control.
- **原生快速与受控快速** - 原生快速模式接近上游轻量执行，不默认启用任务契约、Document Plan 或 Goal Loop 自动修复；受控快速模式保留轻量来源边界和显式检查。
- **Document quality slimming** - Correspondence drafts, focused dispute questions, and small professional reports keep evidence matrices, audit notes, and internal reasoning outside the formal body unless explicitly requested.
- **文档质量瘦身** - 回信、局部争议判断和小型专业报告默认不把证据矩阵、审计记录和内部推理写入正式正文，除非用户明确要求。
- **Tender production pipeline** - Tender Workbench stages now depend on each other: document analysis, BOQ five-step pricing, WORK PLAN AND PROPOSED METHODOLOGY, programme/resource/cost/cash-flow planning, formal submission documents, and final audit.
- **投标生产流水线** - 投标工作台阶段形成依赖链：标书分析、BOQ 逐项五步法组价、WORK PLAN AND PROPOSED METHODOLOGY、进度/资源/成本/现金流计划、正式递交文件和最终审查。
- **Controlled BOQ pricing agents** - BOQ five-step pricing has a dedicated capability pack and skill. Large BOQ scopes can use controlled child agents with narrow briefs, allowed sources, assigned items, and report paths; child agents cannot spawn further agents.
- **受控 BOQ 组价智能体** - BOQ 五步法组价拥有专用能力包和 skill。大型 BOQ 可使用受控子智能体，但子智能体只接收窄 brief、允许来源、分配条目和报告路径，且禁止继续派生。
- **Formal tender deliverables** - After construction planning, Agent Pi reserves a formal submission-document stage for WORK PLAN AND PROPOSED METHODOLOGY, construction programme, labour/material/plant plan, cash-flow plan, and other tender-required formats.
- **正式投标递交文件** - 施工策划后新增正式递交文件阶段，覆盖 WORK PLAN AND PROPOSED METHODOLOGY、施工进度计划、人材机计划、现金流计划及其他标书要求格式。

## Safety Notes / 安全说明

Tender Workbench still treats the project working directory as an output location, not an automatic source corpus. BOQ pricing and formal submission documents should be based on registered sources, selected knowledge-base entries, and ready upstream capability packs.

投标工作台仍将项目工作目录视为成果保存位置，而不是自动来源语料库。BOQ 组价和正式递交文件应基于登记来源、用户选定知识库以及已就绪的上游能力包。
