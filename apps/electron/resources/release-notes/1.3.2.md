# Agent Pi 1.3.2

Agent Pi 1.3.2 is an emergency reliability release for long Markdown/document deliverables.

## Highlights

- **Transactional long-document writing** - Professional Document, Strict Delivery, and Multi-Agent Deep modes now require a manifest-first artifact workflow: section chunks are written and verified before the final Markdown file is assembled.
- **No one-shot long Markdown writes** - The system prompt now tells agents not to push a full long deliverable through one Write call, one heredoc, or one oversized inline Python/Bash command.
- **Explicit write targets** - Long-document Write/Edit retries now require the exact target path/file_path on every tool call, preventing validation failures where the model sends only content.
- **Section-level recovery** - If a section write fails, Goal Loop instructs the agent to resume from the manifest and completed chunks, retry only the failed section, and then reassemble the final artifact.
- **Artifact integrity checkpoints** - Automatic repair prompts now require verification of the final artifact path, section count, required headings, and non-empty content before completion.
- **Guide-first execution for sources and skills** - External MCP/API/Knowledge Base tools now remain blocked until their `guide.md` has been read in the current context. Mentioned skills also remain blocked until `SKILL.md` is read, preventing connector-call errors and shallow skill execution from memory.

## Safety Notes

This release does not change normal short-file Write/Edit behavior. The new recovery path only activates for failed Markdown/text artifact writes that look like long-document truncation, payload-size, heredoc, or command-length failures.
