# Agent Pi 2.2.5 / Agent π 2.2.5

Agent Pi 2.2.5 is a stability and responsiveness patch for large Tender Workbench sessions. It reduces expensive file-tree rescans, keeps automation services dormant unless configured, narrows startup reconciliation work, and adds production diagnostics for renderer exits and memory peaks.

Agent π 2.2.5 是面向大型投标工作台会话的稳定性与流畅性补丁。本版减少昂贵的文件树重复扫描，仅在配置存在时启动自动化服务，缩小启动阶段的状态校准范围，并新增生产环境 renderer 退出和内存峰值诊断日志。

## Highlights / 亮点

- **Lazy session file tree** - The right-side session file panel now performs shallow initial scans and loads folder children only when the user expands that folder. Large Official Outputs and tender artifact directories no longer force a full recursive scan on every refresh.
- **会话文件树懒加载** - 右侧会话文件面板初始只做浅层扫描，用户展开文件夹时才加载该目录子项。大型 Official Outputs 和投标产物目录不会在每次刷新时强制全量递归扫描。
- **Production stability log** - Release builds now write an always-on `stability.log` with renderer process gone events, renderer unresponsive/responsive transitions, child-process exits, uncaught exceptions, unhandled rejections, and memory peak snapshots.
- **生产稳定性日志** - 发布版新增常驻 `stability.log`，记录 renderer 退出、renderer 卡死/恢复、子进程退出、未捕获异常、未处理 Promise 拒绝和内存峰值快照。
- **Lower idle background work** - Automation systems are created only when a workspace has `automations.json`; removing the file disposes the runtime. Permission-mode reconciliation now targets the selected, processing, and explicitly non-default sessions instead of scanning every session.
- **降低空闲后台负担** - 仅当工作区存在 `automations.json` 时才创建自动化系统；删除配置会释放运行时。权限模式校准只处理当前选中、运行中和明确非默认的会话，不再遍历全部会话。
- **Regression coverage** - Added tests for lazy file loading and stability telemetry peak detection, and adjusted watcher timing tests to match the safer debounce window.
- **回归覆盖** - 新增文件懒加载和稳定性内存峰值检测测试，并按更稳妥的 debounce 窗口修正 watcher 时序测试。

## Diagnostics / 诊断

If the app closes unexpectedly or becomes unusually heavy, inspect:

如果应用异常关闭或变得明显卡顿，请优先查看：

`C:\Users\<user>\.agent-pi\logs\stability.log`

The log is rotated at 5 MB and is intended for crash and memory diagnosis, not normal task output.

该日志 5 MB 轮转，专用于崩溃与内存诊断，不用于普通任务输出。
