# Agent Pi 1.2.0

Agent Pi 1.2 focuses on document-work throughput, optional precision extraction, and safer long-running agent runtime behavior.

## Highlights

- **Unified file preview actions** — Markdown sidecars now bring consistent edit, Markdown export, PDF export, and DOCX export actions across chat attachments, conversation file links, and right-side output files.
- **AI selection rewrite in Markdown edit mode** — Select text in an editable Markdown preview, ask the active session to rewrite it with project memory context, preview the proposed replacement, then apply it back into the selected range.
- **Optional MinerU precision extraction** — MinerU is bundled as an optional PDF/scanned-document enhancement. It remains off by default, requires a workspace opt-in plus a workspace-scoped token, and records Markdown, raw JSON, cleanup audit, manifest, and citation provenance when enabled.
- **Optional AnySearch MCP setup** — AnySearch MCP is available as a recommended search connector, but installs disabled and unauthenticated. Saving an API key marks it ready but does not enable it silently.
- **Folder attachment semantics fixed** — Selecting a folder now passes the local absolute folder path as a path-only attachment instead of uploading every file inside it.
- **Spawned sub-agent working directories fixed** — Sub-agents inherit the parent session working directory unless an explicit working directory is supplied.
- **Construction schedule skill** — Added a project-level skill for generating Primavera P6 XML, Microsoft Project XML, and Candy General Importer-compatible planning artifacts from construction narratives and method statements.
- **Idle Pi runtime cleanup** — Completed Pi-backed sessions now release idle `pi-agent-server` Bun subprocesses after a short delay, reducing memory pressure when many sub-agents have finished.

## Safety Notes

MinerU and AnySearch are not enabled by default. Token or API-key presence alone is not enough to activate either integration.
