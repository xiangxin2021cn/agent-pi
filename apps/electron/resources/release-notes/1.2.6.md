# Agent Pi 1.2.6

Agent Pi 1.2.6 polishes the desktop visual system and fixes the new Agent Pi logo presentation.

## Highlights

- **Transparent Agent Pi logo assets** — replaced the previous white-background logo usage with transparent PNG assets for the top-bar symbol and sidebar brand mark.
- **Logo sizing fixed** — the top-bar and sidebar logo no longer rely on forced CSS cropping, avoiding clipped top/bottom edges.
- **Refined Agent Pi default theme** — the default light and dark themes now use a more cohesive Agent Pi aqua, lime, teal, and deep-blue palette.
- **Warm theme added** — added an `Agent Pi Warm` preset for users who prefer ivory, ember, and warm-brown document workspaces.
- **Bronze eye-comfort theme added** — added an `Agent Pi Bronze` preset for long reading, review, and lower-cold-light usage.
- **Theme RGB variables improved** — preset themes now generate RGB variables for info, success, and destructive colors, so shadows and highlights follow the selected theme more consistently.

## 中文说明

- **透明 Agent Pi 标识资源** — 顶部符号和侧栏品牌位改用透明 PNG，不再受白底影响。
- **修复 logo 上下裁切** — 顶部和侧栏 logo 不再依赖强制 CSS 裁切，避免上下边缘显示异常。
- **默认主题精修** — 默认浅色和深色主题进一步贴合 Agent Pi 的青绿、湖蓝、深蓝品牌色系。
- **新增暖色主题** — 新增 `Agent Pi Warm`，适合偏象牙白、琥珀、暖棕的文档工作环境。
- **新增护眼古铜主题** — 新增 `Agent Pi Bronze`，适合长时间阅读、审稿和低冷光使用。
- **主题 RGB 变量增强** — 预设主题会同步生成 info、success、destructive 的 RGB 变量，让阴影、高亮和主题色保持一致。

## Safety Notes

This release only changes visual assets, theme presets, and theme variable generation. It does not change agent execution, file handling, model routing, or project data storage behavior.
