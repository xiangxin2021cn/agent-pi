# Agent Pi 1.2.5

Agent Pi 1.2.5 fixes a Goal Loop false failure in document and spreadsheet production tasks.

## Highlights

- **Transient helper scripts no longer fail deliverable audits** — temporary files under the session `data` directory are ignored as formal output evidence and do not block completion when the requested output is verified.
- **Windows output paths with spaces are captured correctly** — paths such as `South Africa\...\Agent Pi Outputs\...\report.xlsx` are now extracted as full local paths.
- **Formal output evidence promotion** — verified files inside the formal output directory are accepted as requested output evidence when their extension matches the requested format, such as XLSX.

## 中文说明

- **临时脚本不再误判正式交付物** — 会话 `data` 目录下的中间脚本不再进入正式输出审查，也不会在真实交付物已验证时阻塞完成。
- **支持带空格的 Windows 输出路径** — 例如 `South Africa\...\Agent Pi Outputs\...\report.xlsx` 这类路径现在可以完整识别。
- **正式输出证据提升** — 位于正式输出目录且扩展名满足请求格式的已验证文件，会被作为有效交付物证据。

## Safety Notes

This does not weaken missing-output checks. Real missing deliverables, wrong output directories, wrong requested formats, unresolved non-transient tool failures, and explicit runtime/system errors still fail the audit.
