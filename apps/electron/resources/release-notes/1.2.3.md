# Agent Pi 1.2.3

Agent Pi 1.2.3 fixes the in-app What's New panel so it includes the V1.2.1 and V1.2.2 notes and reports the same latest version as the packaged app.

## Highlights

- **What's New release notes fixed** — Adds the missing bundled V1.2.1 and V1.2.2 release-note files so the in-app update history no longer stops at V1.2.0.
- **Scratch notes hidden** — The release-note loader now only displays versioned `X.Y.Z.md` files, preventing the unreleased `next.md` scratch file from entering sorting or display logic.
- **Release-note regression coverage** — Adds a release-note test that checks the latest visible release note matches the root app package version.
- **Completed-session read state fixed** — Viewing a settled session now persists the latest read marker even when `hasUnread` is already false, preventing older completed tasks from reappearing as unread after reinstall or restart.

## Safety Notes

Release notes are bundled with the installed app. Existing installations cannot receive new in-app release-note files until a new app version is installed.
