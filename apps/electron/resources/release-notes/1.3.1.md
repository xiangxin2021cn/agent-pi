# Agent Pi 1.3.1

Agent Pi 1.3.1 is an emergency stability release for knowledge-base scoped document work, real multi-agent dispatch, Goal Loop instruction following, and long-document file reading.

## Highlights

- **Knowledge-base scoped execution guardrails** - Selected enterprise knowledge-base/file-memory sources are now injected as first-class task scope. The agent is instructed to query the selected knowledge base before scanning the working directory, and Goal Loop now pauses for manual review when the assistant asks the user to confirm scope or choices.
- **Real multi-agent dispatch enforcement** - Multi-Agent Deep mode now requires real spawned chapter sessions before final synthesis. Complex Professional Document and Strict Delivery tasks can also get a bounded helper-agent plan after the main session decides orchestration. Goal Loop rejects outputs that merely claim chapter handoffs without actual spawned child sessions.
- **Working-folder input-scope guardrails** - The working directory is framed as a project boundary and output location, not a default evidence corpus. Document and research workflows should analyze selected knowledge sources, attached files, or explicitly named files/folders, and ask before broad folder discovery.
- **Goal Loop instruction-following guardrail** - Automatic improvement now checks the original user instruction, follow-up feedback, selected sources, named chapters/files/folders, output format, and response language before judging document quality. Initial automatic repair is capped at two passes; after that the task moves to user review.
- **Long-document Read EOF handling** - Pi-backed Read now treats "offset beyond end of file" as a successful end-of-file signal instead of a tool failure. This prevents long Markdown/document pagination from failing after the model reaches the final page.

## Safety Notes

Write and Edit tools were checked for the same offset-pagination issue. They do not use Read-style offsets; normal write/edit permission or exact-match failures still surface as real tool errors.
