# Agent Pi 2.2.3 / Agent π 2.2.3

Agent Pi 2.2.3 upgrades Tender Workbench BOQ pricing into a calculable, auditable production-data package for downstream methodology, schedule, resource, cost, and cash-flow planning.

Agent π 2.2.3 将投标工作台 BOQ 组价升级为可计算、可审计的生产数据包，为后续施工策划、进度、资源、成本和现金流计划提供可靠输入。

## Highlights / 亮点

- **Calculable productivity** - Every BOQ item records production rate, duration, calendar, activity linkage, source, and assumptions. Calculated capacity must cover the stated quantity.
- **可计算工效** - 每个 BOQ 条目记录生产率、持续时间、日历、活动关联、来源和假设，计算产能必须覆盖对应工程量。
- **Initial cash-flow distribution** - Item-level period allocations carry amount or weight, source, assumptions, and activity linkage for independent audit and downstream aggregation.
- **初始现金流分期** - 条目级分期记录金额或权重、来源、假设和活动关联，可独立审计并供下游汇总。
- **Deterministic cross-batch gates** - Merge rejects conflicting resource units, cost rate units, productivity assumptions, and activity calendars across controlled child-agent reports.
- **确定性跨批次门禁** - 合并时拒绝受控子智能体报告之间冲突的资源单位、费率单位、工效假设和活动日历。
- **Coverage before readiness** - Missing fields, omitted or extra BOQ items, and altered child results keep the stage blocked instead of silently producing a partial pack.
- **覆盖完成后才就绪** - 缺失字段、遗漏或越界 BOQ 条目以及被改动的子报告结果都会阻断阶段，避免静默产出不完整数据包。
- **Regression hardening** - Source tests now exclude generated installer copies and use deterministic Windows-safe path, watcher, MCP, and headless-server checks.
- **回归加固** - 源码测试排除安装包生成副本，并采用确定性的 Windows 路径、监听、MCP 和无头服务检查。

## Compatibility / 兼容性

Existing BOQ source files remain supported. A BOQ five-step pricing pack becomes ready only after its structured item reports provide the new planning and cash-flow fields.

现有 BOQ 源文件继续支持；但 BOQ 五步法能力包只有在结构化条目报告补齐新的计划与现金流字段后才能进入 ready 状态。
