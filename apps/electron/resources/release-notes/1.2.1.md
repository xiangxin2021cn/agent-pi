# Agent Pi 1.2.1

Agent Pi 1.2.1 turns the V1.2 document-workbench direction into a release focused on higher-quality professional outputs, reusable enterprise knowledge, and more reliable export behavior.

## Highlights

- **Document Quality Composer** — Adds industry-aware visual detection, source-backed diagram/table requirements, evidence-rich Markdown conventions, and stricter document-quality audit signals.
- **Professional report visuals** — Establishes construction Gantt foundations with WBS grouping, baseline/current plan, progress line, critical path, milestones, legends, and A4/A3 landscape export intent.
- **Export stability** — Markdown image assets are resolved for export; Mermaid remains editable in Markdown while export can render stable SVG output; missing image assets fail loudly instead of producing blank documents.
- **Template fidelity direction** — Strict template matching is treated as a code-level DOCX/OOXML template-rendering problem instead of prompt-only styling.
- **Enterprise Knowledge Base** — Generated `.md`, `.txt`, and `.json` artifacts can be promoted into file-memory MCP knowledge sources with category/folder metadata and explicit user activation.
- **Cross-platform packaging** — Windows installer validation remains local, while GitHub Actions can generate macOS DMG/ZIP and Linux AppImage assets for the same release tag.

## Safety Notes

No fabricated charts, maps, simulation figures, investment metrics, or template-fidelity claims. Missing inputs should become audit issues or missing-input tables.
