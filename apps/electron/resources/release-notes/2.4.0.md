# Agent Pi 2.4.0 / Agent 派 2.4.0

Agent Pi 2.4.0 restructures the tender workbench around business reality: BOQ pricing now batches by BOQ page (one COTO chapter per subagent), children verify market rates online, machine gates stop deadlocking on format technicalities, and the nine micro-stages consolidate into five business stages.

Agent 派 2.4.0 按业务实质重构投标工作台：BOQ 组价改为按 BOQ 页（每个 COTO 章节一个子智能体）分批，子智能体联网询价核证费率，机器门禁不再因格式细节死锁，九个碎阶段收敛为五个业务阶段。

## Tender Workbench Restructure / 投标工作台重构

- **BOQ pricing batches follow business boundaries** — Batches are segmented by BOQ sheet chapter (each BOQ page ≈ one COTO chapter, capped at 25 items) instead of mechanical 12-item chunks. Schedule summary rows and synthetic composite groupings are excluded from pricing and reported as skipped items.
- **BOQ 组价批次按业务边界切分** — 批次按 BOQ 页/COTO 章节切分（上限 25 条），取代过去每 12 条机械切断。汇总行与人造组合项不进入组价，并在监控中明示为已跳过。
- **Children verify market rates online** — The C5.1 brief now requires web price verification (fuel, wages, plant hire, cement, aggregates, asphalt, subcontract) with `rateBasis.webEvidence` links; unverifiable rates stay `unverified` instead of being invented.
- **子智能体联网询价** — C5.1 任务书强制关键费率联网核证并在 `rateBasis.webEvidence` 留存链接与查询日期；无法核证的费率标记 unverified，禁止编造。
- **Format issues no longer deadlock batches** — Child reports pass through lenient normalization (numbers, percents, extra keys), and per-item validation replaces whole-batch rejection. Arithmetic self-consistency findings are human-review warnings; completeness and BOQ identity remain the hard gates.
- **格式问题不再锁死批次** — 报告先经宽容归一化（数字、百分数、多余字段），再逐条校验；算数一致性降级为人工复核警告，完整性与 BOQ 身份仍是硬门禁。
- **Runtime owns the merged pricing pack** — When every batch is accepted, the runtime writes `packs/boq-five-step-pricing.json` deterministically from child reports; hand-assembled inline packs are ignored, ending the compression/deep-equal retry loop for pricing the same way 2.3.4 ended it for document analysis.
- **合并定价包由运行时接管** — 全部批次验收后由运行时确定性合并写包，忽略手工内联拼装，彻底消除定价阶段的压缩/深比较重试循环。
- **Main sessions resume automatically** — When the tender task board finishes, the parent session now auto-resumes to review reports and advance the stage instead of waiting silently.
- **主会话自动闭环** — 批次全部完成后主会话自动恢复，审阅报告并推进阶段，不再无声停摆。
- **Nine stages → five business stages** — 项目与资料确认 → 招标文件与合规分析 → BOQ 逐页组价与投入确认 → 施工策划、进度与成本 → 出稿与递交审查。旧阶段 ID 自动映射，老项目照常加载。
- **九阶段收敛为五阶段** — 投标承诺确认并入组价阶段，施工策划/进度/成本合并，出稿与递交审查合并；旧阶段 ID 走别名映射，既有项目状态不丢失。
- **Monitoring shows real failure reasons** — The project overview now surfaces invalid batch errors, normalization warning counts, and skipped summary rows instead of bare status labels.
- **监控台展示真实失败原因** — 项目总览直接列出未通过验收批次的错误、归一化警告数和跳过的汇总行。

## Notes / 说明

- Existing BOQ pricing runs built on summary rows or composite items should reset the pricing stage: redo `boq_reconciliation` with real per-row BOQ items, then restart the stage so per-page batches dispatch with web-verified rates.
- 基于汇总行或人造组合的旧定价批次应在升级后重置该阶段：先用真实 BOQ 逐行条目重做 `boq_reconciliation`，再重新进入阶段按页派生并联网核价。
