# Agent Pi 2.1.1 / Agent π 2.1.1

Agent Pi 2.1.1 keeps narrow source analysis bounded and strengthens verifiable professional delivery. It separates reader-facing content from internal controls, tracks requested artifact formats explicitly, and prevents unverified assumptions or incomplete sub-agent work from being accepted as final.

Agent π 2.1.1 让局部来源分析保持边界，并强化可验证的专业交付。正文与内部控制产物分离，指定交付格式被显式追踪，未经验证的假设或未完成的子智能体工作不能被接受为最终成果。

## Highlights / 亮点

- **Quick source analysis** - Single-page, single-table, and bounded-range questions default to one result table, one concise explanation, and one confirmation item without automatic five-section or multi-agent expansion.
- **快速来源分析** - 单页、单表和局部范围问题默认输出一张结果表、一段简明解释和一个待确认事项，不自动扩展为五章或多智能体任务。
- **Evidence-neutral briefs** - Sub-agent briefs contain only the assigned question, scope, allowed sources/files, and report destination. Unverified parent conclusions and calculations are not copied into the brief.
- **证据中立 brief** - 子智能体 brief 只携带问题、范围、允许来源/文件及报告路径，不复制主会话未经验证的结论和计算结果。
- **Structured assumption gate** - Evidence matrices use a versioned JSON schema. Claims marked `assumption` or `unverified` cannot be promoted to unconditional core conclusions, and zero source coverage cannot pass.
- **结构化假设门禁** - 证据矩阵使用版本化 JSON Schema；标记为 `assumption` 或 `unverified` 的声明不能无条件进入核心结论，零来源覆盖不能通过。
- **Activity-based handoff lifecycle** - Active sub-agents are monitored through advancing activity and report readiness rather than a fixed wait. Stale work is surfaced, and contradictory handoffs block merge.
- **活动式交接生命周期** - 子智能体按持续活动和报告就绪状态监控，不再固定等待；停滞任务会被识别，交接结论冲突会阻止合并。
- **Goal completion gate** - Agent-side attempts to set a session to `done` are rejected until Goal Audit has passed.
- **Goal 完成门禁** - Goal Audit 通过前，智能体调用会话 `done` 会被拒绝。
- **Explicit artifact formats** - Markdown, Office, data, and professional formats are tracked as explicit deliverables. PDF is not generated unless requested, and DOCX export preserves A3/A4 portrait or landscape page intent.
- **显式产物格式** - Markdown、Office、数据和专业格式作为明确交付物追踪；未要求时不生成 PDF，DOCX 导出保留 A3/A4 纵横向页面意图。
- **Source-backed visuals** - VisualSpec validates captions, alt text, source references, reusable data sidecars, and page intent before professional visuals are accepted.
- **有依据的专业图表** - VisualSpec 在接受专业图表前校验图注、替代文本、来源引用、可复用数据伴随文件和页面意图。
- **Reader-facing document quality** - Evidence matrices, Goal Audit records, assumption registers, and visual manifests remain internal by default. Goal Audit checks body cleanliness, table balance, visual media, requested structure, and export quality.
- **正文质量控制** - 证据矩阵、Goal Audit、假设登记和视觉清单默认保持内部；Goal Audit 检查正文整洁度、表格比例、视觉媒体、指定结构和导出质量。

## Safety Notes / 安全说明

V2.1.1 does not treat a working directory as a source corpus by default, does not allow nested sub-agent spawning, and does not silently bypass required user confirmation. Unverified evidence remains conditional until a source resolves it.

V2.1.1 默认不把工作目录视为来源语料库，不允许子智能体递归派生，也不静默绕过必要的人工确认。未经验证的证据在来源确认前必须保持条件表达。
